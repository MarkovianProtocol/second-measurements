# SM-018 — Time from a CNA's own disclosure date to CVE List publication, 2025–2026 records, against CNA Operational Rules 4.5.1.4

Paper: https://markovianprotocol.com/measurements/sm-018.html · DOI and log leaf on the page

Script: `python3 -I cve72.py cves.zip out/` — reads the cvelistV5 midnight archive directly (the `cves.zip` inside the release asset `*_all_CVEs_at_midnight.zip.zip`), takes every PUBLISHED record with a 2025 or 2026 ID, and scores `datePublished` (CVE List) minus `containers.cna.datePublic` (the CNA's own public date) in whole days. Dell's `datePublic` is read in India time (+05:30). Dropped: records whose public date precedes the ID's reservation date, and records whose public date is after publication. "Own site" means the CNA cites its own domain in the record (OWN map in the script). Late = more than three whole days. Writes `cve72_summary.json` and `cve72_rows.json` (every scored record with both dates). `make_page.py` builds the page from those files and `page_template.html`.

Exhibits: CNA Operational Rules v4.0, v4.1.0, v4.2.0 (PDF) and the v4.2.0 text; CVE Record Format schema 5.1; the Program's partner roster (CNAsList.json); the twenty longest-wait records as published; the four worked-instance advisories (ZDI-25-950, Dell DSA-2025-153, Arista Security Advisory 0126, Drupal SA-CONTRIB-2026-031); prior art (Drupal issue 3589998, GitHub discussion 200225, arXiv 2604.20765); per-CNA and per-quarter CSVs; dataset provenance with hashes. `secondpath/` holds the four advisory-date checks (scripts, every page read, retrieval logs, results). SHA256SUMS in exhibits/.
